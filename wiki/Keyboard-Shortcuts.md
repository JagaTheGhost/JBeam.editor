# Keyboard Shortcuts

| Category | Shortcut | Action |
| :--- | :---: | :--- |
| **File & Editor** | <kbd>Ctrl + S</kbd> | Save active JBeam file |
| | <kbd>Ctrl + Z</kbd> / <kbd>Ctrl + Y</kbd> | Undo / Redo |
| | <kbd>F2</kbd> | Cascading Node Rename (with optional `X-Mirror` symmetry) |
| | <kbd>Ctrl + F</kbd> | Find / Replace in Monaco editor |
| **Workspace Layout** | <kbd>Ctrl + B</kbd> | Toggle Primary Sidebar (Left) |
| **3D Selection & Tools** | <kbd>V</kbd> | Select Tool |
| | <kbd>B</kbd> | Box Select (Marquee) Tool |
| | <kbd>Shift + Click</kbd> | Multi-select nodes |
| | <kbd>Alt + F</kbd> | Toggle **Connected Topology Focus** (Neighborhood X-Ray) |
| | <kbd>Alt + G</kbd> | Reset 3D gizmo offsets |
| | <kbd>Delete</kbd> | Delete selected node(s), beam, or surface |
| **Simulation** | <kbd>Ctrl + R</kbd> | Reload active vehicle in BeamNG.drive (when SimConnection is active) |
