JBeam.editor Reference Manual

JBeam.editor is a specialized development environment built for BeamNG.drive vehicle designers, modders, and physics engineers. It bridges the gap between raw SJSON source code and real-time 3D WebGL physics skeleton visualization.

Key Architecture

Unlike traditional 3D DCC tools (Blender) or basic text editors (VS Code/Notepad++), JBeam.editor runs both environments side-by-side with lossless bidirectional synchronization:

  • Source to Viewport: Edits in code immediately parse and animate the 3D physics structure.
  • Viewport to Source: Dragging nodes in 3D updates the exact coordinates in the document AST without altering indentation, whitespace, or comments.

2. Workspace Layouts & Popout Windows

JBeam.editor supports flexible layout presets to adapt to laptops, single ultrawide displays, and multi-monitor workstations.

Layout Modes (Toolbar Header)

  • Split View (Default): Shows the Monaco code editor on the left and the 3D WebGL viewport on the right with an interactive draggable splitter.
  • Code Focus: Collapses the 3D viewport to maximize code editing area for heavy scripting.
  • 3D Focus: Maximizes the 3D viewport for detailed structural inspection, beam measurement, and node manipulation.

Detached Multi-Monitor Viewport (v0.2Beta Enhanced)

Click the Detach Viewport button on the toolbar to pop out the 3D viewport into its own standalone window across multi-monitor setups. In v0.2Beta, the detached viewport is completely self-contained:

  • Built-in Toolbars & Sidebars: Hosts its own Assembly Manager, dedicated 3D Meshes (.DAE) Panel, and Element Inspector directly in the popout window.
  • Smooth Resizable Splitters: Left and right sidebar panels can be independently resized and collapsed.
  • Seamless Keyboard Sync: Forwards shortcut keys (F5 reload, F12 DevTools, Delete, Alt + F, Alt + G) directly to the scene.
  • Fault-Tolerant Error Recovery: Protected with an automatic error boundary to eliminate blank screens during transient GPU or parsing errors.

Clicking the Reattach Viewport button smoothly docks the 3D canvas back into the main IDE layout.

3. Monaco JBeam Code Editor

Powered by the same industry-leading editor behind Visual Studio Code, customized with a dedicated BeamNG grammar.

Capabilities

  • Monarch Syntax Highlighting: Full recognition of BeamNG keywords (nodes, beams, triangles, slots, slots2, variables, flexbodies, etc.).
  • Bracket Pair Colorization: Distinct rainbow brackets for deep nested JSON/SJSON tables.
  • Real-time Code Folding & Minimap: Collapse entire sub-sections or part definitions.
  • Comment Preservation: 100% preservation of single-line (//) and multi-line (/* ... */) comments during automated AST transforms.

4. Bidirectional AST Synchronization

JBeam.editor implements a customized lossless SJSON parser and Abstract Syntax Tree (AST) updater.

How it Works

  1. When a node is selected in 3D and translated along an axis, the coordinate delta is computed.
  2. The AST updater locates the exact line and token index of that node in the source document.
  3. Only the numerical values for [x, y, z] are replaced with high precision, leaving surrounding whitespace and inline annotations intact.

5. 3D Structure Viewport

A WebGL Three.js physics renderer designed specifically for vehicle skeleton structures.

Visual Elements

  • Nodes: Rendered as interactive 3D spheres. Hovering reveals node names and coordinates; clicking selects the node.
  • Beams: Rendered as connecting lines color-coded by their physical function:
NORMAL Beam
HYDRO (Steering/Suspension)
SUPPORT Beam
BOUNDED Beam
ANISOTROPIC Beam
LBEAM
  • Triangles & Quads: Rendered as semi-transparent surfaces with dual-sided lighting for aerodynamic drag and vehicle collision geometry.
  • Node Labels: Billboard text tags floating above each node, toggleable via the Labels button.

Viewport Background Themes & Canvas Customization

Customize the 3D canvas tone in the Overlays dropdown menu to suit your lighting environment:

  • Editor Gray (Default, #1e2127): Smoothly matches the dark gray charcoal editor theme and surrounding panels.
  • Theme Charcoal (#1a1a1a): Pure sidebar and editor background color.
  • CAD Slate (#282c34): Neutral medium CAD slate gray for maximum wireframe clarity.
  • Pitch Black (#0d0e11): High-contrast OLED dark void.

The ground grid features slate-gray center axes (#5e6878) and subtle secondary lines (#2e3440 with 75% opacity) to float cleanly above all background themes without harsh glare.

6. Connected Topology Focus (Neighborhood X-Ray) Experimental Testing

When engineering complex vehicle frames containing thousands of overlapping beams, identifying a node's structural neighbors can be difficult.

Neighborhood X-Ray Capabilities

  • Instant Keyboard Shortcut (Alt + F): Toggles Connected Topology Focus on or off (or via the Overlays dropdown menu).
  • Selective Neighborhood Highlighting: Selecting any node or cluster keeps directly connected beams and adjacent neighbor nodes fully visible, while gracefully dimming unconnected vehicle geometry.
  • Automatic Billboard Label Decluttering: When enabled, floating node labels automatically hide for background elements and only display for the selected nodes and their immediate neighbors.
  • Symmetry Integration: Automatically highlights counterpart connections across mirrored nodes when bilateral symmetry is active.

7. Gizmos & Multi-Node Manipulation

Precise transform manipulation directly inside the 3D viewport.

Multi-Select & Cluster Move

  • Single Selection: Left-click any node in 3D or in the Monaco source editor.
  • Multi-Select: Hold Shift and click additional nodes.
  • Centroid Translation Gizmo: When multiple nodes are selected, a unified gizmo appears at the bounding center of the cluster. Dragging moves all selected nodes simultaneously while preserving their relative geometry.
  • Reset Offsets (Alt + G): Instantly resets node gizmo offsets back to their original coordinates.

8. Blender-Style Orientation Gizmo

Located in the top-right corner of the 3D viewport, this interactive coordinate widget allows instant camera snapping.

Interaction

  • Click Axes: Click on +X, -X, +Y, -Y, +Z, or -Z to snap the camera directly to Front, Rear, Left, Right, Top, or Bottom orthographic view.
  • Drag Rotation: Left-click and drag the orientation sphere to orbit smoothly around the vehicle center.

9. Bilateral Symmetry Engine

BeamNG vehicles rely on strict lateral symmetry across the vehicle centerline ($X=0$).

Mirror Pair Detection

JBeam.editor detects bilateral node pairs based on BeamNG naming conventions:

fr1l <---> fr1r    (Left & Right)
door_fl <---> door_fr
susp_arm_l <---> susp_arm_r

When the Symmetry button is enabled on the toolbar, dragging node f1l in 3D automatically updates f1r with mirrored X coordinates ($-X$).

PCA Symmetry Plane Detection Experimental Testing

For custom scratch-built chassis or mods with non-standard naming, click Analyze PCA Symmetry Planes in the Overlays menu. The engine computes Principal Component Analysis (PCA) eigenvectors across node coordinate clusters to detect the true mathematical mirror plane.

11. Multi-Part Assembly & Slot Manager

Modern BeamNG vehicles consist of dozens of separate .jbeam files connected through a slot hierarchy.

Capabilities

  • Variant (.pc) Loader: Select any vehicle part configuration file to composite all matching chassis, suspension, engine, and body parts into one unified 3D skeleton. Robust parser handles unquoted keys and comments in legacy files.
  • Interactive Slot Swapping: Change parts using slot dropdown menus (e.g. swap standard cab for a sleeper cab).
  • Independent Part Visibility: Click the eye icon 👁️ next to any part in the assembly list to hide or isolate specific sections.
  • Part Color Coding: Toggle between coloring by Beam Type and coloring by Vehicle Part to distinguish overlapping sub-assemblies.

12. Dedicated 3D Meshes (.DAE) Panel & Multi-Spawn

Align physics skeletons against 3D visual models (.dae) and generate JBeam parts directly from Collada geometry.

Submesh Explorer & Multi-Mesh Spawning

  • Submesh Checkboxes: Browse discovered submeshes (e.g. hood, fenders, chassis) with polycount and triangle statistics. Check individual parts to spawn multiple body panels simultaneously.
  • Filter Tabs: Filter submeshes by All, Spawned, or For JBeam.
  • Spawn All / Despawn All: 1-click controls to show or hide all submeshes in the 3D viewport.
  • 1-Click JBeam Part Generator: Automatically calculates the composite 3D bounding box for all spawned meshes and creates a new .jbeam part with pre-configured flexbodies bindings and structural bounding cage.
  • Secondary Window Integration: The dedicated Meshes panel is fully available inside both the main studio window and the detached viewport window.

13. Mechanical Workspace & Powertrain Studio Experimental Testing

A comprehensive mechanical analysis and vehicle dynamics suite for BeamNG powertrains, steering racks, and engine dynamics.

Dyno & Torque Curves Experimental Testing

  • Interactive RPM Scrubbing: Real-time horsepower and torque curve graphs with peak power/torque readouts at specific RPMs.
  • Gearing & Sawtooth Calculator: Calculates wheel speeds and transmission gear shifts based on tire radius, gear ratios, and final drive.

Ackermann Steering Kinematics Simulator Experimental Testing

  • Lock-to-Lock Angle Simulator: Interactive slider visualizing inside vs outside wheel steering angle divergence in real-time.
  • Steering Rack Hydro Analysis: Automatically extracts steering hydro beams and calculates rack travel limits and extension rates.

Device Architecture Tree & 3D Navigation

  • Device Hierarchy: Scans engines, clutches, automatic/manual gearboxes, transfer cases, differentials, shafts, halfshafts, mounts, and fuel storage.
  • Focus 3D & Jump to Code: Instantly centers the 3D viewport on bound device nodes or jumps directly to device definitions in Monaco source code.

14. Live Simulation Connection

Connect JBeam.editor directly to a running instance of BeamNG.drive via a real-time socket bridge.

Real-time Features

  • Live Deformation Mirroring: Watch nodes deform and deflect in JBeam.editor as your vehicle crashes in real-time in BeamNG.
  • Instant Vehicle Reload (Ctrl + R): Reloads the active vehicle in BeamNG without reloading the game or map.
  • Bidirectional Node Selection: Selecting a node in JBeam.editor highlights that exact node in the simulator's debug mode.

15. Diagnostics & Problems Panel

Catches common syntax errors, broken references, and geometry bugs before you test in-game.

Automated Checks

  • SJSON Syntax Errors: Unterminated brackets, missing commas, or corrupted tokens.
  • Dangling Beams: Beams that reference non-existent node IDs.
  • Duplicate Nodes: Multiple nodes sharing identical identifier names within the same part.
  • Degenerate Triangles: Collinear nodes forming triangles with zero surface area.
  • Non-numeric Coordinates: Catches invalid strings or missing coordinate components.

16. Installer & Auto-Updates

Packaging and continuous update mechanisms for JBeam.editor.

Web Bootstrapper

A lightweight, frameless installer featuring:

  • Automatic discovery of Steam and BeamNG.drive installation folders.
  • File associations for .jbeam and .pc files with custom icons.
  • Right-click context menu integration (Open with JBeam.editor).

In-App Update Checker

JBeam.editor silently queries GitHub Releases API on startup. When an update is detected, an authentic BeamNG-themed banner appears below the toolbar with a 1-click update link.
